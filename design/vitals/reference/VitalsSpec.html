F · 她的状态 · 说明

给实现的人：规则、文案、数据

三件要我定的事
1 · 中文名 她的状态

和「她的主页」「她的手和眼」一套叫法：外面是你在看她，页面里是她说「我」。「Ash 状态」把名字写死了（她能改名）；「运行状态」是技术词。图标：暖深棕底 + 薄荷色心电线（薄荷 = 她醒着），应用网格里不是「正常」时右上角带一个同色小点。

2 · 状态灯三档
正常ok-fill 灯芯 · ok-soft 光晕 · ok 文字 留意warn-fill · warn-soft · warn 有问题err-fill · err-soft · err

用「留意」不用「注意」：「注意」像警告牌，「留意」是「心里有个数，已经好了」。另有两种不算档位的：刚到（薄荷色，开机第一分钟）、过期 / 读不到（灰色空心）。

3 · 小组件放什么

改成每个数都配一张小图，不再只摆两个数。4×2：负载、CPU、内存、今天花，四格各一张小图。2×2：CPU + 今天花（费不费电、费不费钱）。4×4：CPU 和负载叠成一张大图，下面是内存、近 7 天花费，最底下是今天做的事 / 想了几次 / 出错 / 断线。

负载 = 每分钟流转的消息数；CPU、内存、负载都是最近 1 小时、每分钟一个点；花费是近 7 天。出事时越界的那条图变红并画出正常上限的虚线，不用点开就知道是哪里。

已恢复的告警只给「知道了」+ 一行「常这样的话，跟我说一声」。「重启我的大脑」点了先弹确认（大约 10 秒、正在做的事会中断），确认后才执行，这一步就是审批；「去…」只是跳页面。「复制详情发给开发者」复制原始事件（id、值、top），界面上不显示这些。

数据缺口（要开发补，或者先这样）
  1. 「反应快不快」没有真正的响应时间。只有大脑的 event-loop 延迟 lag_p99_ms。第一版就用它，它说的是「我手上的事卡不卡」，不包括等模型回话的时间。
  2. 今天断线重连几次，现在算不出来。minute 行里没有 link 计数。在 minute 行加一个 link_opens 就能加总。
  3. 已恢复的告警「持续了多久」没有。事件只记开始，同一条 10 分钟才记一次。建议恢复时记一条 type: "ok" 事件，带 since。
  4. 事件里的 note 是英文，写给开发看的。界面按 id 用上面的固定文案；以后由她自己写。
  5. App 本身的 CPU、内存、耗电是第二阶段；到时在「此刻」下面加一行「手机上的 Ash」，同样三格。
小组件实现要点
  • 小图要一个新的卡片部件。现在的 A2UI 部件里只有 ProgressBar，画不了折线和柱。建议加一个 Spark：{kind: "Spark", type: "line" | "bars", values: [...], max?, limit?, tone, hi?: {from, to?, tone}}，原生渲染成位图（CardViews 已经有位图预算，一张 64×30dp 的小图约 70 KB）。颜色只传令牌名（her-fill、err-fill、warn-fill、you-mark、surface-3），暗色跟系统。
  • 数据：CPU / 内存 / 负载 = service:health recent {kind: "minute", limit: 60} 的 cpu_pct / rss_mb / msg；4×2、2×2 里负载每 3 分钟并成一根（取最大）。花费 = usage.get 的 by_day 最近 7 天。
  • 纵轴：数据最大值的 1.25 倍，但 CPU 不低于 15%、负载不低于 20 条/分，免得 2% 的抖动被画成尖峰。内存从 0 开始，平就是稳。
  • 颜色规则：平时一律薄荷色（她醒着）；花费柱灰色、今天那根珊瑚色。越界的那段 / 那几根换 err-fill，一小时内已经过去的那段换 warn-fill；正常上限的虚线只在出事时画。数字跟着变色。
  • 时间写钟点，不写「x 分钟前」。小组件不会实时重画，「3 分钟前」最多会差 15 分钟。告警也写「14:02 起」。
  • 过期不清空。现在 CardView.Expired 会把卡片换成一行「已过期」。改成照常画上一次的卡，所有颜色（包括小图）换成 text-3 / surface-3、灯变空心灰，右上角换成「已过期 · 最后 12:31」。这对所有 Ash 卡片都适用。
  • 刷新：灯一变就推；图和数字最多 15 分钟推一次；60 分钟没推就是过期。
  • 外框：沿用「Ash 卡片」（圆角 22、内边距 14），卡片自己画标题行，外框的 card_title 不显示；颜色从 widget_bg / widget_fg 换成 ash_surface / ash_ink / ash_text_2 / ash_text_3。4×4 = 330×330 也是现有尺寸。点哪里都打开「她的状态」。
