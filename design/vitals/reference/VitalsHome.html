1状态头一盏灯 + 她说的一句话。灯三档：正常（ok）/ 留意（warn）/ 有问题（err），灯芯用 *-fill，光晕用 *-soft，背后有一团同色的淡光。只有「有问题」的灯外圈会慢慢涨落，减少动画时不动。下面两个小签：连着几台设备、闲着还是在忙（在忙时写在忙什么）。
2此刻三格，先说人话（很闲 / 不多 / 很快），数字小字放下面。分档：忙不忙 = CPU 5% 以下很闲、30% 以下有点忙、再往上很忙；内存 300 MB 以下不多、600 以下有点多；反应 50 毫秒以下很快、200 以下有点慢、再往上卡住了。越界的那格字变色。
3今天五个数一行：做的事（和「她的主页」同一个数）、想了几次（找模型的次数）、花了、断线重连、出错。为 0 的变淡。底下一句话解释「想了几次」和钱的关系。
4最近告警没有就一行「最近一切正常」。有就按时间倒序，最多 5 条：她用「我」说发生了什么，下面一行是实际值对比正常范围。点开是详情。
5体检 · 手和眼全好时收成一行「7 处都好」，点进去是现有的体检页。有待办时只列出有问题的部位 + 琥珀色「去修」，直接跳到体检页对应部位。
6体检 · 运行六条底线，每条一句人话 + 实际值和正常范围 + 正常 / 越界。只在她闲着时才算的几条，她在忙时写「在忙，不算」。
7最近 24 小时两条小柱：做事（每小时消息数）、CPU。最右一根是现在（薄荷色），出过告警的那一小时标红。不做交互。
8安静正常时整页没有一个红色或琥珀色；颜色只用来指出哪里不对。
